# ---- Core DL / HF stack ----
# IMPORTANT: transformers>=4.49.0 is REQUIRED -- `Qwen2_5_VLForConditionalGeneration`
# (the correct class for Qwen2.5-VL; note the underscore-5-underscore) was only added
# in that release. Anything below 4.49.0 will raise ImportError. We use a lower-bound
# instead of an exact pin here (unlike the rest of this file) because we can't verify
# exact inter-package patch compatibility offline -- let pip's resolver pick compatible
# accelerate/tokenizers/safetensors versions above these floors instead of trusting a
# guessed-at exact patch number.
transformers>=4.49.0
accelerate>=1.2.0
bitsandbytes>=0.44.1

sentencepiece>=0.2.0

# (search_engine/*.py --s/--q/--qa + --rerank calls). Not needed for Phase 2,

peft>=0.13.0


# ---- Vision-language & visual-similarity ----
# NOTE: qwen-vl-utils is intentionally NOT installed. This pipeline only ever
# feeds Qwen2.5-VL still keyframe images (never raw video), but qwen-vl-utils
# unconditionally imports decord/av at module load time for its video code
# path, and those wheels are built against an older numpy C-ABI. On Kaggle's
# numpy 2.0.2 base image that raises `ValueError: numpy.dtype size changed,
# may indicate binary incompatibility` on import. src/phase2_captioning/
# vlm_captioner.py loads images directly with Pillow instead -- the HF
# Qwen2.5-VL image processor already does its own smart-resize internally, so
# nothing is lost.
#
# SigLIP (visual-text similarity, frame_selector.py fast path) uses
# transformers' AutoModel/AutoProcessor -- SiglipModel has been supported
# since transformers>=4.37, already covered by the pin above. No extra
# package needed beyond transformers + Pillow (already listed below).
# If you switch config/settings.yaml's siglip_model_id to a "siglip2-*"
# checkpoint, bump transformers to >=4.49 first.

# ============================================================
# Kaggle install notes:
#   1) faiss-gpu wheels on PyPI are CPU-only for py>=3.11 on some
#      mirrors -- if `import faiss` fails to see the GPU, run:
#        pip uninstall -y faiss-gpu faiss-cpu
#        conda install -y -c pytorch -c nvidia faiss-gpu=1.7.2
#      (Kaggle notebooks have conda available via `!conda`.)
#   2) OCR runs on RapidOCR (onnxruntime) by default -- no CUDA-matched
#      wheel to fight with. If `import onnxruntime` can't see the GPU
#      provider, it silently falls back to CPU, which is fine for
#      per-keyframe OCR.
#   3) If Kaggle's preinstalled numpy isn't 1.26.4 when this file is
#      installed (`import numpy; numpy.__version__` -- check first),
#      pip will try to downgrade it to satisfy the pin below. That's
#      normally fine, but if any *other* preinstalled Kaggle package
#      was compiled against numpy 2.x specifically, downgrading numpy
#      can itself trigger a fresh ABI mismatch elsewhere. If you hit
#      that, either drop the numpy==1.26.4 pin and let pip resolve a
#      version compatible with everything already in the image, or
#      restart the Kaggle kernel after installing so nothing has been
#      imported yet against the old numpy.
# ============================================================
